El Panel Principal es la página de destino después del inicio de sesión. Proporciona un resumen de los módulos activos y operaciones disponibles para el usuario según su grupo de autorización.

![Panel principal del WMS mostrando tarjetas de módulos](/docs/wms/dashboard/dashboard-es.png)

## Resumen del Panel

El panel muestra:

- **Módulos Activos** — tarjetas para cada módulo al que el usuario tiene autorización.
- **Notificaciones** — alertas y mensajes del sistema.
- **Estado de Red** — indicador en línea/fuera de línea y calidad de conexión.

## Módulos Activos

Según el rol del usuario, pueden aparecer los siguientes módulos:

| Módulo | Descripción |
|--------|-------------|
| Entrada de Mercancía | Recibir mercancía entrante |
| Confirmación de Entrada | Confirmar mercancía recibida |
| Picking | Preparar órdenes para despacho |
| Conteo | Conteos físicos de inventario |
| Transferencia | Mover inventario entre ubicaciones |
| Confirmación de Transferencia | Confirmar transferencias |
| Transferencia Directa | Transferencias rápidas de artículos |
| Revisión de Artículo | Consultar información de stock |
| Revisión de Ubicación | Consultar contenido de ubicaciones |
| Configuración | Administración del sistema |

## Navegación

Haga clic en cualquier tarjeta de módulo para navegar a ese módulo. La barra lateral o navegación superior muestra las subpáginas disponibles según el módulo actual.

## Indicador de Calidad de Red

El panel muestra el estado de la red en tiempo real:

| Estado | Descripción |
|--------|-------------|
| Conexión Excelente | Conexión fuerte y estable |
| Buena Conexión | Conexión estable |
| Conexión Débil | Conectividad intermitente |
| Fuera de Línea | Sin conexión a internet |

## Notificaciones

El panel de notificaciones muestra:

- Aprobaciones pendientes
- Alertas del sistema
- Mensajes de estado de sincronización
- Notificaciones de error

Haga clic en la campana de notificaciones para ver todos los mensajes. Haga clic en **Marcar todo como leído** para limpiar las notificaciones.
