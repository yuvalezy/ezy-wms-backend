---
title: Devices
description: View and manage all registered WMS devices — activate, disable, rename, and audit status history.
---

The Devices page lists every device that has ever accessed the WMS. A Super User can activate new devices, disable unused ones, rename them, and review the full audit trail of status changes.

:::note
Only **Super Users** can access Settings → Devices.
:::

## Device List

![Device list showing search bar, status filter, and device cards](/docs/wms/settings/devices/devices-list.png)

The list shows one card per registered device containing:

| Field | Description |
|-------|-------------|
| **Device Name** | Human-readable label assigned on first registration |
| **UUID** | Unique identifier generated by the device browser |
| **Registration Date** | Date the device first logged in |
| **Status** | Current status badge — Active, Inactive, or Disabled |

Use the **Search** field to filter by name or UUID. Use the **All Statuses** dropdown to filter by status.

:::tip
When you log in on a device that is Inactive, a yellow banner appears at the top of the list with a quick **Activate Device** button so you can activate it in one step.
:::

## Device Details

Click **View Details** on any card to open the device detail dialog.

![Device details dialog — Details tab](/docs/wms/settings/devices/devices-details.png)

The **Details** tab shows:
- Device Name and current Status
- Full Device UUID
- Registration Date
- Status Notes (reason recorded for the last status change)

Two action buttons are available at the bottom:
- **Update Status** — change the device status (Activate / Disable)
- **Change Name** — rename the device

## Audit History

Click the **Audit History** tab inside the device detail dialog to see the full log of status changes.

![Device audit history tab showing a status-changed entry](/docs/wms/settings/devices/devices-audit.png)

Each entry records:
- Action type and timestamp
- User who made the change
- Reason provided
- Previous status → New status

## Updating Device Status

From the Details tab, click **Update Status** to open the status form.

![Update Device Status dialog](/docs/wms/settings/devices/devices-status-form.png)

1. Select the **New Status** from the dropdown (Active or Disabled).
2. Enter a **Reason** for the change (required, 10–500 characters).
3. Click **Update Status**.

The change is recorded in the device's Audit History.

:::caution
Setting a device to **Disabled** immediately blocks all users from logging in on that device.
:::

## Changing Device Name

From the Details tab, click **Change Name** to rename the device.

![Change Device Name dialog](/docs/wms/settings/devices/devices-name-form.png)

1. Clear the current name and enter a new **Device Name** (3–100 characters).
2. Click **Change Name**.

Device names must be unique across the system.

## Device Statuses

| Status | Description |
|--------|-------------|
| **Active** | Fully operational; users can log in |
| **Inactive** | Newly registered; login blocked until activated by a Super User |
| **Disabled** | Manually blocked by an administrator |
