---
title: Transfer Confirmation Process
description: Scan and confirm transferred items at destination.
---

The Transfer Confirmation Process works identically to the Goods Receipt Confirmation Process. Operators scan items that have been transferred to confirm they arrived correctly at the destination.

## Accessing the Page

Route: `/transferConfirmation/:scanCode`

Navigation: Dashboard → Transfer Confirmation → Select Entry

## How to Use

1. Select the confirmation entry from the list.
2. Scan the **barcode** of each transferred item.
3. Confirm or modify the **quantity**.
4. Select the **unit type**.
5. Click **Accept**.

## Error Messages

| Message | Cause |
|---------|-------|
| Entry not valid | The confirmation number does not exist |
| Entry is closed | The confirmation has already been completed |
