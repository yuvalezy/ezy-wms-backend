## Core Modules

### Item Management

- [Item Check](/docs/item-management/item-check) — Query stock by item code or barcode.
- [Bin Check](/docs/item-management/bin-check) — View all items in a bin location.

### Goods Receipt

- [Goods Receipt Process](/docs/goods-receipt/process) — Receive incoming merchandise.
- [Goods Receipt Supervisor](/docs/goods-receipt/supervisor) — Create and manage receipt entries.
- [Goods Receipt Reports](/docs/goods-receipt/reports) — Review receipt data and discrepancies.

### Receipt Confirmation

- [Confirmation Process](/docs/receipt-confirmation/process) — Confirm received goods.
- [Confirmation Supervisor](/docs/receipt-confirmation/supervisor) — Manage confirmations.

### Picking

- [Picking Process](/docs/picking/process) — Pick items for outgoing orders.
- [Picking Detail](/docs/picking/detail) — Focus on a single picking line.
- [Picking Check](/docs/picking/picking-check) — Verify picked items.
- [Picking Supervisor](/docs/picking/supervisor) — Monitor picking operations.
- [Picking SAP Integration](/docs/picking/sap-integration) — Generate pickings from SAP.

### Counting

- [Counting Process](/docs/counting/process) — Perform physical inventory counts.
- [Counting Supervisor](/docs/counting/supervisor) — Create and close counts.
- [Counting Summary Report](/docs/counting/summary-report) — Review count results.

### Transfer

- [Transfer Process](/docs/transfer/process) — Move inventory between bins.
- [Transfer Supervisor](/docs/transfer/supervisor) — Create and finish transfers.
- [Transfer Approval](/docs/transfer/approval) — Approve cross-warehouse transfers.
- [Transfer Request](/docs/transfer/transfer-request) — Create transfer requests.

### Transfer Confirmation

- [Transfer Confirmation Process](/docs/transfer-confirmation/process) — Confirm transfers.
- [Transfer Confirmation Supervisor](/docs/transfer-confirmation/supervisor) — Manage confirmations.

### Direct Transfer

- [Direct Transfer](/docs/overview/direct-transfer) — Quick single-item transfers.

### Reports

- [Reports Overview](/docs/reports) — Run live, read-only SQL reports against your SAP data.
- [Running a Report](/docs/reports/running-a-report) — Filter, sort, page, and export a report.
